# 实现距离计算和服务半径检查功能

## 问题分析

1. **未解决距离的问题**：`Canteen` 接口缺少坐标信息，无法计算用户到食堂的距离
2. **未在服务半径内的未弹窗提示无法下单**：`canAddToCart` 函数只检查了食堂状态，没有检查服务半径

## 解决方案

### 1. 更新 `Canteen` 接口

* 在 `types.ts` 中为 `Canteen` 接口添加坐标字段：

  ```typescript
  latitude: number;
  longitude: number;
  ```

### 2. 实现距离计算和服务半径检查

* 在 `HomeView.tsx` 中更新 `canAddToCart` 函数，添加服务半径检查：

  * 导入 `isWithinServiceRadius` 函数

  * 检查用户位置是否在食堂服务半径内

  * 不在服务半径内时弹窗提示

### 3. 完善 `SearchView.tsx` 中的服务半径检查

* 为 `SearchView` 组件添加 `userCoords` 参数

* 更新 `canAddToCart` 函数，添加服务半径检查

### 4. 完善 `ProductDetailsView.tsx` 中的服务半径检查

* 为 `ProductDetailsView` 组件添加 `userCoords` 参数

* 更新 `canAddToCart` 函数，添加服务半径检查

### 5. 确保所有页面的服务半径检查逻辑一致

* 确保三个页面的 `canAddToCart` 函数都包含相同的服务半径检查逻辑

* 弹窗提示文案统一为："您不在该食堂的服务范围内，暂时无法下单"

## 实现步骤

1. 更新 `types.ts` 中的 `Canteen` 接口
2. 修改 `HomeView.tsx` 中的 `canAddToCart` 函数
3. 修改 `SearchView.tsx` 组件，添加 `userCoords` 参数和服务半径检查
4. 修改 `ProductDetailsView.tsx` 组件，添加 `userCoords` 参数和服务半径检查
5. 测试所有页面的服务半径检查功能

## 预期效果

* 当用户点击"加入购物车"按钮时，系统会检查：

  * 食堂是否处于关停或繁忙状态

  * 用户是否在食堂服务半径内

* 如果任何一个条件不满足，都会弹窗提示用户无法下单的原因

* 只有当食堂状态正常且用户在服务半径内时，才会将商品添加到购物车

## 注意事项

* 确保用户位置获取功能正常工作

* 确保食堂数据中包含正确的坐标信息

* 距离计算和服务半径检查逻辑要准确

* 弹窗提示文案要清晰明了
