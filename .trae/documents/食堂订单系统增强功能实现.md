# 食堂订单系统增强功能实现计划

## 1. 需求分析
- 显示食堂状态，关停和繁忙状态下不允许下单
- 读取开启配送状态，未开启只支持自提，开启支持配送和自提
- 订单页面支持获取当前用户定位，根据定位离食堂的距离由近及远排序
- 计算用户与食堂的位置，读取服务半径，不在服务半径内的食堂不允许下单
- 不允许下单使用弹窗提示

## 2. 实现步骤

### 2.1 添加位置服务
- 创建 `utils/location.ts` 文件，实现获取用户位置的功能
- 实现位置权限请求和错误处理
- 提供获取当前坐标的函数

### 2.2 实现距离计算功能
- 在 `utils/location.ts` 中添加距离计算函数
- 实现基于经纬度的距离计算（Haversine公式）
- 添加服务半径检查函数

### 2.3 增强食堂状态显示
- 修改食堂选择组件，显示食堂状态（开启/关停/繁忙）
- 为不同状态添加视觉标识（颜色/图标）
- 在商品页面顶部显示当前食堂状态

### 2.4 添加弹窗组件
- 创建 `components/common/AlertPopup.tsx` 组件
- 实现可复用的弹窗，支持标题、内容和确认按钮
- 添加动画效果

### 2.5 实现配送状态控制
- 在订单页面检查食堂的 `isDeliveryActive` 状态
- 根据状态动态显示配送选项
- 未开启配送时，只显示自提选项

### 2.6 更新订单创建逻辑
- 在创建订单前检查食堂状态
- 检查用户是否在服务半径内
- 检查配送状态限制
- 不符合条件时显示弹窗提示

### 2.7 排序食堂列表
- 修改 `canteenService.ts`，添加按距离排序功能
- 实现 `getNearbyCanteens` 函数，根据用户定位排序
- 在食堂选择页面应用距离排序

### 2.8 测试和优化
- 测试所有功能的正常流程
- 测试边界情况（如位置权限被拒绝）
- 优化用户体验，确保弹窗提示清晰明了

## 3. 关键文件修改

### 3.1 新增文件
- `utils/location.ts` - 位置服务和距离计算
- `components/common/AlertPopup.tsx` - 弹窗组件

### 3.2 修改文件
- `services/canteenService.ts` - 增强食堂获取和排序功能
- `pages/CheckoutView.tsx` - 添加订单限制检查
- `pages/CanteenSelectView.tsx` - 显示食堂状态和排序
- `components/layout/CanteenHeader.tsx` - 显示食堂状态
- `services/orderService.ts` - 添加订单创建前的限制检查

## 4. 技术要点
- 使用浏览器 Geolocation API 获取用户位置
- 实现 Haversine 公式计算两点之间的距离
- 使用 Zustand 管理用户位置状态
- 使用 Framer Motion 实现弹窗动画
- 确保所有异步操作都有适当的错误处理

## 5. 预期效果
- 用户可以看到食堂的实时状态
- 只能从开启状态的食堂下单
- 配送选项根据食堂设置动态显示
- 食堂列表根据距离排序
- 不在服务半径内的食堂不允许下单
- 所有限制都有清晰的弹窗提示

这个计划将确保实现用户需求的所有功能，同时保持代码的可维护性和良好的用户体验。
